# Prompts

เก็บ prompt แยกหนึ่งไฟล์ต่อหนึ่งงาน ตั้งชื่อตาม hub และหน้าที่ของ prompt ให้โมดูลฝั่ง server เป็นผู้โหลดข้อความ

ใช้ JSON Schema จาก `schemas/` สำหรับ Structured Outputs และตัดข้อมูลให้เหลือเฉพาะฟิลด์ที่จำเป็นก่อนส่งเข้าโมเดล ให้อ้างอิงด้วย `book_id` และ `source_id` และตอบว่าไม่พบในแค็ตตาล็อกเมื่อไม่มีข้อมูล
