# ShelfPilot AI — Project brief

> Original team brief, kept for humans. AI instructions live in `CLAUDE.md` and `.claude/rules/`; this file is reference only.

## Core

ทีมต้องการสร้าง ShelfPilot AI ผู้ช่วยค้นหาหนังสือเล่มและจัดการหนังสือสะสมสำหรับผู้อ่านมังงะและไลต์โนเวลในประเทศไทย ปัจจุบันประกาศหนังสือออกใหม่กระจัดกระจายอยู่ตามโซเชียลมีเดียของแต่ละสำนักพิมพ์ ขณะที่ชื่อเรื่องภาษาไทยและญี่ปุ่น ฉบับพิมพ์ และเลขเล่มอาจระบุไม่เหมือนกัน ทำให้ผู้อ่านติดตามได้ยากว่ามีเล่มใดออกใหม่ ตนเองมีเล่มใดแล้ว และควรซื้อเล่มใดต่อ

ภายในงาน เราจะพัฒนาเว็บต้นแบบที่สาธิตการทำงานได้ครบกระบวนการ โดยเริ่มจากประกาศของสำนักพิมพ์จำนวนจำกัดที่ได้รับอนุญาติให้ใช้ แล้วให้ AI สกัดชื่อเรื่อง สำนักพิมพ์ เลขเล่ม ฉบับ และวันวางจำหน่ายเป็นแค็ตตาล็อกที่มีลิงก์อ้างอิงแหล่งข้อมูล ผู้ใช้สามารถบันทึกเล่มที่มีอยู่แล้ว เพื่อรับรายการหนังสือออกใหม่เฉพาะบุคคล การแจ้งเตือนเล่มที่ยังขาด และคำแนะนำที่อธิบายเหตุผลได้ หากระบบไม่มั่นใจว่าข้อมูลหมายถึงหนังสือเล่มเดียวกัน จะระบุให้ตรวจสอบแทนการรวมข้อมูลโดยอัตโนมัติ พร้อมเชื่อมต่อไปยังรายการจำหน่ายหนังสือเล่มที่ตรงกัน โดยให้ผู้ใช้ยืนยันก่อนออกไปยังหน้าซื้อสินค้า

MVP จะใช้แค็ตตาล้อกขนาดเล็ก และทดสอบกรณีประกาศซ้ำ ชื่อเรียกหลายแบบ และฉบับหนังสือที่ไม่ตรงกัน เราจะใช้ Codex ระหว่างงานเพื่อพัฒนาและทดสอบการนำเข้าข้อมูล การจับคู่หนังสือ และประสบการณ์ผู้ใช้ แนวคิดนี้ผสาน AI-Native Products & Operations กับ Deep Domain AI ผ่านระบบค้นหาที่เข้าใจลำดับเล่ม ฉบับหนังสือ และหนังสือที่ผู้ใช้มีอยู่แล้ว ในระยะยาว ระบบอาจช่วยสำนักพิมพ์และผู้ขายบนมาร์เก็ตเพลสเชื่อมประกาศหนังสือใหม่กับความต้องการซื้อที่เกี่ยวข้อง โดยประเมินจากความแม่นยำในการจับคู่ ประโยชน์ของการแจ้งเตือน และจำนวนการคลิกไปยังหน้าซื้อสินค้า

## กฎวิศวกรรมกลางที่คุมทั้ง 6 ฟีเจอร์ (Core Architecture Rules)

* **ยุบเหลือ 3 จุดเรียก LLM (3 LLM Hubs):** เพื่อทำเสร็จทัน 6 ชั่วโมง ให้รวมงานเป็น **1) Ingestion Pipeline** (ข้อ 4+5+6), **2) Interactive Chat Hub** (ข้อ 1+2), และ **3) Recommendation Engine** (ข้อ 3)
* **คุมต้นทุน Token ตั้งแต่ต้นทาง:** ห้ามส่งไฟล์ JSON ทั้งก้อนเข้า LLM — ใช้ **Function Calling + Local Search** ดึงเฉพาะรายการที่เกี่ยวข้อง, คำนวณเลขเล่มที่ขาดด้วยโค้ด (0-Token), ตัดฟิลด์ URL/รูปปกออกก่อนส่งเข้า Prompt (Payload Pruning) และแยกปุ่มลัดพื้นฐานเป็น **0-Token Fast Path**
* **ID-Based Citation & Safe Guardrails ทุกจุด:** บังคับ LLM อ้างอิงผ่าน `book_id` และ `source_id` เท่านั้น (ห้ามพิมพ์ URL เอง), แจ้งตรงๆ เมื่อไม่มีข้อมูลในแค็ตตาล็อก, มี **Approval Gate** ก่อนอัปเดตคลังหนังสือ และมี **Confirmation Modal** ยืนยันชื่อเรื่อง-เลขเล่ม-ฉบับพิมพ์ทุกครั้งก่อนพาออกไปยังหน้าร้านค้า
