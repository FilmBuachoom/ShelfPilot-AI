# Badge

One or two words of edition or status; every badge carries a text label, so color is never the only cue.

| Variant | Class | Meaning |
|---|---|---|
| Edition | `sp-badge--edition` | มังงะ · นิยาย · บ็อกซ์เซ็ต · บิ๊กบุ๊ก — neutral outline, never colored |
| New | `sp-badge--new` | new / upcoming volume (`accent-soft` + `accent-ink`) |
| Missing | `sp-badge--missing` | volumes the user lacks — dashed, matches VolumeStrip |
| Verified | `sp-badge--verified` | fact backed by a stored source |
| Review | `sp-badge--review` | `needs_review` or confidence < 0.8; show the score |
| Info | `sp-badge--info` | `distinct_edition` created |
| Muted | `sp-badge--muted` | `duplicate_merged` — informational only |
