# AskBar

A floating pill above the BottomNav on the shelf screen that opens the AI assistant — the only place the AI add-on appears on the baseline home screen.

- Placeholder hints at both AI jobs: asking, and updating the shelf in plain language.
- Tapping opens the assistant (full screen on mobile, right panel on desktop) with the text field focused.
- Hide it entirely when AI is disabled or unavailable; the shelf must still work without it.
