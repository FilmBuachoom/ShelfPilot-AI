# FilterTabs

Horizontally scrolling pill tabs that filter the shelf: ทั้งหมด · มังงะ · นิยาย · ขาดเล่ม · ใกล้ออก, each with a count.

- Selected tab is solid `ink` with `surface` text (monochrome, like OpenAI) — never orange; orange is for actions.
- Edition filters (มังงะ / นิยาย) reuse the edition vocabulary from Badge; add บ็อกซ์เซ็ต / บิ๊กบุ๊ก only if the shelf has them.
- Single-select; counts update with search.
