# ConfirmModal

Centered modal that restates title, volume and edition in large type before the user leaves for an external store.

- The three facts sit in a `surface-subtle` summary (`sp-confirm`); values in 16px/600 so they can be checked at a glance.
- Edition is always shown as an edition badge — this is where manga vs novel mix-ups get caught.
- The note line makes clear the store is external.
- Same anatomy as ApprovalSheet: summary → one full-width action → ghost cancel.
