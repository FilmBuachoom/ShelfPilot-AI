# BottomNav

Four-tab mobile navigation starting from the baseline — คลังของฉัน (home) · ออกใหม่ · แนะนำ · ผู้ช่วย — in monochrome: active tab is `ink` + 600 weight, others `ink-muted`.

- คลังของฉัน and ออกใหม่ are baseline; แนะนำ and ผู้ช่วย are AI add-ons and can be hidden when AI is off.
- The only color is an `accent` dot on ออกใหม่ for unread announcements.
- Hidden from `bp-desktop` up, where a left rail replaces it and the assistant opens as a right panel.
- Icons: 24px, 1.75 stroke, `currentColor`.
