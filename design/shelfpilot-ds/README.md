# ShelfPilot AI

แอปจัดการ **คลังมังงะและไลท์โนเวล (LN/Manga Inventory)** ที่มี AI เป็นผู้ช่วยเสริม ตัวคลังคือแกนหลักของระบบ ส่วน AI (แชท อัปเดตด้วยภาษาธรรมชาติ คำแนะนำ และการดึงข้อมูลจากประกาศ) เป็นชั้นที่ต่อยอดจากคลังและ **ตรวจสอบที่มาได้ทุกคำตอบ**

หน้าตาเป็นแนว **"OpenAI calm + Shopee commerce cards"** คือโครงหลักเรียบ สงบ เป็นขาว-ดำแบบ OpenAI ส่วนการ์ดหนังสือ การนับถอยหลังวันวางแผง และขั้นตอนยืนยันใช้ความคุ้นมือแบบ Shopee ที่คนไทยใช้ทุกวัน

Keywords: **สงบ · คุ้นมือ · ตรวจสอบได้**

## ขอบเขต: Baseline และ Add-on

| ชั้น | ฟีเจอร์ | Component |
|---|---|---|
| **Baseline: คลังหนังสือ** | ดูคลัง, กรอง/ค้นหา, เพิ่มเรื่อง, ติ๊กเล่มเอง, ดูเล่มที่ขาด, ไปหน้าร้าน | ShelfHeader, FilterTabs, SeriesRow, VolumeStrip, Badge, Button, ConfirmModal, BottomNav |
| Add-on: AI Assistant | ถามคำถาม (ฟีเจอร์ 1), อัปเดตคลังด้วยภาษาธรรมชาติ (ฟีเจอร์ 2) | AskBar, Composer, QuickChip, ChatMessage, CitationChip, ApprovalSheet |
| Add-on: AI Recommendation | คำแนะนำพร้อมเหตุผล (ฟีเจอร์ 3) | BookCard, CitationChip |
| Add-on: AI Ingestion (Admin) | ดึงข้อมูลจากประกาศ, จับคู่ประกาศซ้ำ, แยกฉบับพิมพ์ (ฟีเจอร์ 4–6) | ReviewQueueItem |

**กฎ:** คลังต้องใช้งานครบได้โดยไม่ต้องพึ่ง AI ถ้า AI ล่มหรือ token หมด ผู้ใช้ยังเพิ่ม/ติ๊ก/ดูเล่มขาดได้ตามปกติ

## หลักการ 6 ข้อ

0. **คลังมาก่อน (Shelf first)** หน้าแรกคือ "คลังของฉัน" และทุกอย่างที่ AI ทำต้องจบที่การเปลี่ยนแปลงที่เห็นได้ในคลัง (ช่องเล่มเปลี่ยนจากเส้นประเป็นทึบ) AI เป็นทางลัด ไม่ใช่ทางเดียว

1. **ขาว-ดำเป็นค่าเริ่มต้น ส่วนสีส้มใช้กับการลงมือทำ** ประมาณ 90% ของหน้าจอใช้ `surface`, `ink`, `ink-muted`, `line` ส่วนสีส้ม (`accent`, `action`) ใช้เฉพาะจุดที่ผู้ใช้ต้องลงมือหรือเกี่ยวกับการซื้อ ได้แก่ ปุ่มยืนยัน ปุ่มไปหน้าร้าน ป้าย "ใหม่" และการนับถอยหลัง **หนึ่งหน้าจอมีปุ่ม `action` ได้ไม่เกิน 1 ปุ่ม**
2. **แยก "AI พูด" ออกจาก "ข้อมูลจริง"** คำตอบของ AI เป็นข้อความเปล่าไม่มี bubble ส่วนข้อมูลจากแค็ตตาล็อกต้องแสดงเป็น BookCard, VolumeStrip หรือ CitationChip เสมอ และห้ามมี URL ดิบอยู่ในข้อความ
3. **การเขียนข้อมูลทุกครั้งต้องผ่านจุดยืนยัน** ApprovalSheet (ก่อนลงคลัง) และ ConfirmModal (ก่อนพาออกไปร้าน) ใช้รูปแบบเดียวกัน คือสรุปรายการ แล้วตามด้วยปุ่ม `action` เต็มความกว้าง
4. **ความไม่แน่ใจต้องมองเห็นได้** ถ้า confidence ต่ำกว่า 0.8 หรือรายการอยู่ในสถานะ `needs_review` ให้ใช้กลุ่มสี `review-*` และขอบเส้นประ ห้ามซ่อนและห้ามเดา
5. **ปุ่มแบบ 0-Token ต้องตอบทันที** QuickChip มีสัญลักษณ์ ⚡ และแสดงผลทันทีโดยไม่มี typing indicator

## เสียงและถ้อยคำ

- ปุ่มขึ้นต้นด้วยกริยาและบอกจำนวน เช่น "ยืนยัน 5 เล่ม", "ไปหน้าร้าน", "ตรวจและรวม" ไม่ใช้คำว่า "ตกลง" ลอยๆ
- เลขเล่มใช้ en dash เช่น "เล่ม 9–12" ส่วนชื่อเรื่องย่อใช้ "ฯ" ตามที่ผู้ใช้คุ้น เช่น "สปายฯ" หรือ "หมอยาฯ"
- เมื่อไม่มีข้อมูลให้บอกตรงๆ ว่า "ยังไม่พบในแค็ตตาล็อก" แล้วเสนอทางต่อ ห้ามเดาคำตอบ
- ข้อความแชทใช้ภาษาสุภาพแบบเป็นกลาง สั้น และให้คำตอบมาก่อนเหตุผล
- ไม่ใช้อีโมจิ ยกเว้นสัญลักษณ์ของระบบ 2 ตัว คือ ⚡ (คำตอบแบบ 0-Token) และ ✦ (เหตุผลที่ AI เขียน)

## สี

| กลุ่ม | Token | ใช้ที่ |
|---|---|---|
| พื้นและตัวอักษร | `surface`, `surface-subtle`, `surface-raised`, `ink`, `ink-muted`, `line` | ทุกหน้าจอ |
| แบรนด์และการลงมือทำ | `accent`, `accent-soft`, `accent-ink`, `action`, `on-action` | CTA, ป้ายเล่มใหม่, นับถอยหลัง |
| มีหลักฐาน | `verified-soft`, `verified-ink` | จุดใน citation pill, ป้าย "มีแหล่งอ้างอิง" |
| ไม่แน่ใจ | `review-soft`, `review-ink`, `review-line` | คิว needs_review, confidence ต่ำ |
| ฉบับใหม่ | `info-soft`, `info-ink` | distinct_edition |

ข้อกำหนด:
- `accent` (#f05a28) มีคอนทราสต์ 3.4:1 บนพื้นขาว จึง **ห้ามใช้กับตัวอักษรเล็ก** ถ้าเป็นข้อความสีส้มให้ใช้ `accent-ink`
- ข้อความบนปุ่ม `action` ต้องใช้ `on-action` เสมอ (ในธีมมืดจะเป็นตัวอักษรสีเข้ม)
- ห้ามใช้สีส้มของ Shopee (#EE4D2D) หรือโลโก้ Shopee ตรงๆ เพราะเรามีปุ่มพาออกไปหน้าร้าน ถ้าหน้าตาเหมือนกันผู้ใช้จะแยกไม่ออกว่าตอนนี้อยู่ที่ไหน

### สถานะของเล่มและประกาศ

| สถานะ | รูปแบบ |
|---|---|
| มีแล้ว (owned) | ช่องทึบสี `ink` |
| ขาด (missing) | ช่องเส้นประ `ink-muted` |
| กำลังออก/ใหม่ (upcoming) | พื้น `accent-soft`, ขอบ `accent` |
| มีแหล่งอ้างอิง (verified) | `verified-*` + ✓ |
| ต้องให้คนตรวจ (`needs_review`) | `review-*` + ขอบเส้นประ |
| ฉบับใหม่ (`distinct_edition`) | `info-*` |
| ประกาศซ้ำที่รวมแล้ว (`duplicate_merged`) | `surface-subtle` + `ink-muted` |

**Edition Badge** (มังงะ · นิยาย · บ็อกซ์เซ็ต · บิ๊กบุ๊ก) เป็นกรอบ outline สีกลางที่มีคำกำกับเสมอ ห้ามใช้สีแยกฉบับ เพราะฉบับพิมพ์เป็นประเภท ไม่ใช่สถานะ

## ตัวอักษร

- **Inter + Noto Sans Thai** (Google Fonts) เป็นฟอนต์ UI ทั้งหมด (`--font-sans`) ได้ความเรียบแบบ OpenAI และตัวไทยอ่านชัดบนมือถือ
- **IBM Plex Mono** (`--font-mono`) ใช้กับ `book_id`, `source_id`, `raw_text` และ diff ในหน้ายืนยัน
- ข้อความไทยต้องมี line-height อย่างน้อย 1.6 (`text-body` = 16/26) และตัวเลขเล่มใช้ `font-variant-numeric: tabular-nums`

## ระยะ ขอบ และเงา

- ใช้ grid 4px (`space-1`–`space-7`) ระยะขอบจอมือถือคือ `space-4` และระยะระหว่างข้อความแชทคือ `space-5`
- ปุ่ม, chip, composer และ citation ใช้ `radius-pill` การ์ดใช้ `radius-md` ส่วน bubble ผู้ใช้, modal และ sheet ใช้ `radius-lg`
- แยกพื้นผิวด้วย `line` เป็นหลัก ใช้เงาแค่ 3 จุด คือ composer (`shadow-card`), bottom sheet และ modal

## Layout

- **มือถือ:** Bottom nav 4 แท็บ **คลังของฉัน (หน้าแรก)** · ออกใหม่ · แนะนำ · ผู้ช่วย
  - หน้าคลัง: ShelfHeader (สรุปจำนวน) → FilterTabs → รายการ SeriesRow → AskBar ลอยเหนือ nav เป็นทางเข้า AI
  - แตะ SeriesRow เพื่อเปิดหน้ารายเรื่อง ซึ่งมี VolumeStrip ขนาดเต็มให้แตะติ๊กเล่มเองได้
  - แท็บผู้ช่วยเป็นหน้าแชทเต็มจอ: Composer ทรง pill และ QuickChip
- **Desktop (≥ `bp-desktop`):** คลังเป็นพื้นที่หลักตรงกลาง ส่วนแชทเป็น panel ด้านขวากว้าง `panel-width` (ปิดได้) เมื่อกดยืนยันในแชท ช่องเล่มในคลังเปลี่ยนเป็นทึบทันที (จุด wow ของเดโม)
- **หน้าแนะนำ (Add-on):** แบ่ง section แบบ Shopee เช่น "เล่มที่ควรเก็บต่อ" กับ "แนวเดียวกัน" พร้อมลิงก์ "ดูทั้งหมด ›" และแถว BookCard ที่เลื่อนแนวนอนได้
- **หน้า Admin (Add-on: Ingestion และ Review):** จัดข้อมูลแน่น เป็นตาราง โทนขาว-ดำ ใช้สีเฉพาะ badge สถานะ

## Motion

- ใช้ความยาว 150–200ms แบบ ease-out ไม่มี bounce และไม่มี confetti
- หลังกดยืนยันลงคลัง ช่องเล่มใน VolumeStrip เปลี่ยนจากเส้นประเป็นทึบ (fade 200ms) และการ์ด "ลงชั้น" (translateY 8px → 0)
- คำตอบของ AI แสดงแบบ streaming แต่ QuickChip (0-Token) แสดงทันที
- รองรับ `prefers-reduced-motion` โดยตัด animation ทั้งหมด

## นำไปใช้ในโค้ด (Hackathon 6 ชั่วโมง)

- คัดลอก `tokens.css` และ `components/bundle.css` เข้าโปรเจกต์ แล้วใช้ class `sp-*` ได้ทันที
- ถ้าใช้ shadcn/ui หรือ Nuxt UI ให้ map token ดังนี้: `--action` → primary, `--on-action` → primary-foreground, `--surface` → background, `--ink` → foreground, `--line` → border, `--radius-md` → radius
- **สร้าง Baseline ให้เสร็จก่อน** (ShelfHeader, FilterTabs, SeriesRow, VolumeStrip) แล้วค่อยต่อ AI เข้าไป เพราะทุก add-on ต้องแสดงผลลัพธ์ผ่าน component ชุดนี้
- ให้ความสำคัญกับงานภาพ 2 ชิ้น คือ **VolumeStrip** (แกนของคลัง) และ **CitationChip** (หลักฐานของ AI)

## สิ่งที่ห้ามทำ

- ความรกแบบ Shopee เช่น แบนเนอร์ซ้อนกัน ป้ายแดงทุกจุด หรือ gradient
- รูปแบบที่ดูเป็น AI สำเร็จรูป เช่น gradient น้ำเงิน-ม่วง การ์ดอีโมจิ หรือการ์ดเส้นซ้ายสี
- URL ดิบในคำตอบของ AI หรือปุ่ม `action` สองปุ่มในหน้าจอเดียว
